# Rust/Candle: разделение вокала и инструментала и транскрипция вокала

**Статус:** финальный дизайн-артефакт; независимая проверка билдера пройдена; утверждён пользователем 2026-11-07 («утверждаем»). Следующий шаг — детальный план реализации. Область согласована пользователем. Реализация не начата; тесты не заявлены. В рамках этой задачи коммиты не создавались. Технические gates G1/G2/G3 по-прежнему применяются; права на веса не разрешены. Технические неизвестные вынесены в явные gates (§12), а не угаданы.

**Дата:** 2026-11-07. **Репозиторий:** `/home/alex/sources/candle-roformer` (MIT, `LICENSE`). На момент написания — пустой (только лицензия); кода, тестов, зависимостей, CI нет.

---

## 1. Назначение и цель

Библиотека на Rust, которая: читает аудиофайл → разделяет вокал и инструментал по конкретному чекпоинту → транскрибирует вокал (речь/пение) в текст с таймстампами. Форма продукта: библиотека + тонкий CLI для валидации на реальных файлах. Не GUI, не сервис, не обучение.

Платформы: Windows/Linux с NVIDIA CUDA, macOS с Metal. AMD GPU — явно вне v1.

## 2. Согласованная область (user-approved)

- Стек: Rust + Candle.
- Веса: только локальные файлы. Никаких скрытых сетевых загрузок как предусловия тестов. Автоматических загрузок моделей нет; опциональный офлайн-загрузчик отложен (deferred).
- Итоговые артефакты end-to-end: `vocals.wav`, `instrumental.wav`, текст с таймстампами.
- ASR: Whisper через Candle — принятое решение первого релиза.
- Python — только опциональный офлайн-конвертер весов; в рантайме Python нет.
- Чекпоинт не утверждается нативно поддерживаемым Candle; это открытый вопрос разведки (§6, §12). Любое утверждение о нативной совместимости без доказательств запрещено.

## 3. Архитектура (решения архитектора; не отдельно согласованы пользователем)

Слои: (1) декодирование/ресэмплинг аудио (CPU, независимо от GPU-инференса); (2) движок разделения (точное воспроизведение upstream-модели и инференса); (3) downstream ASR (Whisper через Candle); (4) слой вывода.

Принципы:
- Оркестрация файлов вне ядра PCM-инференса. Ядро работает с буферами PCM; файловая оркестрация — снаружи (тестируемость на буферах без ФС).
- Внутренний аудио-тип с метаданными: частота дискретизации, число каналов, planar, конечные f32. Сохранять выравнивание каналов и длительность входа для стемов.
- ASR работает на отдельной моно/ресэмплированной копии ОТДЕЛЁННОГО ВОКАЛА (Whisper `SAMPLE_RATE 16000` верифицирован в закреплённом `models/mod.rs` Candle; ASR потребляет отдельную копию отделённого вокала), никогда не на оригинальной смеси. Исходные буферы/файлы отделённых стемов для ASR не модифицируются. Тайминги ASR — во времени входного трека.
- Выходные стемы: если нативная SR модели отличается от входной, стемы ресэмплируются обратно к входной SR; сохраняются исходная раскладка каналов и точное число сэмплов входа, выравнивание границ — документированный crop/pad. Архитектурное решение, подлежит верификации.
- Нативная SR и конфиг модели берутся из проверенного соответствующего конфига. Гиперпараметры не придумывать.
- Формула инструментала и любые нормализация/паддинг/оверлап следуют upstream-референсу или явно документируются и покрываются parity-тестами.
- GPU выполняет инференс модели на выбранном поддерживаемом бэкенде; audio IO/DSP может идти на CPU.
- Явный выбор устройства и действенные ошибки вместо тихого CPU-fallback модели.
- Последовательность: сначала разделение, затем ASR. По умолчанию выгружать/освобождать веса разделения перед ASR (ограничение VRAM), если измерения не покажут целесообразность конфигурируемого переиспользования.

## 4. Форматы и данные

- PCM WAV — обязательный первый валидированный файловый путь. Другие кодеки — опционально позже, за слоем декодирования (предложение, не согласованное ограничение).
- Структурированный результат: стемы + сегменты.
- Удобный файловый пайплайн экспортирует 2 WAV-файла плюс UTF-8 текст и JSON-сайдкар с таймстампами (выбор сайдкара — дефолт архитектора).
- Точный публичный API и размер модели Whisper требуют доказательств/плана; автодетекция языка — предложенный дефолт, пользователь может переопределить язык.
- Не обещается точная транскрипция текстов песен; использовать таймстампы сегментов, не выдумывать синхронизацию лирики или попадающие в слово таймстампы.
- «Другие эффекты» неясны — явно отложены; v1 — только два стема.

## 5. API-контракт (именованные типы; точные Rust-сигнатуры/ошибки — деталь реализации, не обещаются скомпилированными)

- `AudioBuffer { sample_rate, channels, planar samples }`
- `SeparatorConfig`
- `LocalSeparationAssets { checkpoint: путь к safe-converted, config }`
- `LocalWhisperAssets { config.json, tokenizer.json, model.safetensors }`
- `DeviceChoice`
- `TranscriptSegment { start_seconds, end_seconds, text }`

Методы: `Separator::load`, `separate(AudioBuffer) -> Stems`; `Transcriber::load`, `transcribe(vocals) -> Transcript`; high-level `separate_and_transcribe_file(request) -> result`; удобная запись 2 WAV + txt + JSON.

Запрос: явный путь к файлу, модели, устройство, выход; язык — auto или явный.

Поведение записи: staging-файлы с rename в финальные по одному только после успеха; не утверждается многофайловая атомарная транзакция; по умолчанию без перезаписи. При сбое очистить собственные staging-файлы, сохранить пользовательские существующие выходы. Повторное использование выходного конфига с перезаписью — только явно.

## 7. Порт модели и DSP (решения архитектора)

- Rust-библиотека + тонкий CLI.
- Локальные модели, без bundled weights/downloader/runtime Python.
- Candle GPU NN на CUDA (NVIDIA, Windows/Linux) и Metal (macOS); CPU-аудио декод/ресэмпл/STFT/ISTFT разрешены; явный выбор устройства; недоступное устройство — ошибка, без тихого neural CPU-fallback.
- Базовая точность f32; fp16/quantized ASR в v1 нет; оптимизации позже только с parity-валидацией.
- Точный порт эталонной архитектуры MelBandRoformer, не обёртка Python/ONNX.
- CPU DSP с Rust FFT (rustfft — кандидат зависимости, веттинг/пиннинг при реализации); парные real/imag f32-передачи на GPU, без требования нативных complex-тензоров; complex mask multiply — явная пара-формула; без custom GPU FFT в v1.
- Обученные операции модели на GPU; Candle gather/scatter/index — только после spike возможностей CUDA+Metal; разрешён math attention вместо flash при равенстве уравнений.
- Операции не гарантированы по одному лишь присутствию enum; если ключевой примитив не работает на бэкенде — STOP как технический gate, без заявления покрытия и без fallback.
- Конфиг v7.yaml не доказан до ограниченной конвертации с покрытием ключей/форм весов, включая буферы/дефолты, и числового сравнения.

## 8. Безопасность и лицензии

- Офлайн-конвертер — опциональный инструмент разработчика, только по явной команде пользователя на явный локальный чекпоинт; `torch.load(weights_only=True, map_location='cpu')` в совместимом restricted-режиме; при неподдержке — fail, без автоматического `weights_only=False`, без динамического unpickling модулей. Изолировать окружение/доверенный источник; проверять pinned SHA256; flatten обёрнутого state_dict только при валидированной структуре; сохранять ожидаемые имена параметров/dtypes/метаданные; генерировать safetensors + манифест конвертации с хэшами/профилем модели. Отсутствующие/неожиданные ключи, включая необученные буферы, — явно; allowlist аудированных исключений, без тихого `strict=false`. Никакой автоматической загрузки `.ckpt` или неограниченной десериализации библиотекой.
- Права на веса НЕИЗВЕСТНЫ; не редистрибьютировать/не бандлить/не кэшировать/не скачивать и не подразумевать, что MIT покрывает веса. Пользователь поставляет законные локальные веса; редистрибуция заблокирована до подтверждения лицензии. Существующий MIT репозитория — только оригинальный код проекта; сторонние уведомления. Не утверждать, что личное/локальное использование автоматически лицензировано. Лицензии зависимостей — аудит при реализации.

## 9. Аудио-обработка

- v1: PCM/float WAV обязательно. Сжатые кодеки отложены, не обещается универсальность входного файла.
- Отклонять: нулевую длину, нефинитные сэмплы, невалидные частоты, >2 каналов.
- Для моно-входа дублировать канал в стерео перед моделью и downmix отделённый вокал обратно в моно; для стерео-входа сохранить два канала без downmix.
- Ресэмплинг модели к 44100 по проверенному профилю; выход — исходная SR/каналы/точное N входных сэмплов.
- Ресэмплинг вокала обратно, затем детерминированный trim/pad на концах; инструментал вычисляется как original PCM − возвращённый вокал на исходной SR (input-waveform residual; parity модели проверяется отдельно).
- Без клиппинга/нормализации, кроме как требует референс; выход float32 WAV для сохранения headroom.
- Инструментал — residual, не второй обученный head.

ASR: только отдельная копия отделённого вокала → mono 16000 Hz; никогда смесь; не модифицировать стемы. Чанкование ASR и сепаратора независимы; смещения сегментов абсолютны от исходной временной шкалы. Whisper: язык auto по умолчанию, мультиязычная модель; рекомендованный baseline — small multilingual (без обещаний скорости/VRAM); принимаются локальные совместимые неквантизованные конфиги Whisper. Использовать Candle Whisper encoder/decoder; реализовать/извлечь decoding/long-form логику с атрибуцией источника, не предполагать, что tensor forward даёт текст. Обработка токенизатора, timestamp-токенов, language/special-токенов, границ EOS/окон; детерминированное подавление дубликатов через границы окон. Таймстампы сегментов, не word alignment. Риск галлюцинаций/точности пения явен; обработка тишины/no-speech и пороги конфигурируемы; не гарантировать корректные тексты песен или число поддерживаемых языков вне загруженной модели.

## 12. Gates и приёмка

**G1** — верифицировать локальную checksum + safe-формат/совместимость ключей/форм/дефолтов с v7, заморозить референсный вызов и манифест; при несовместимости — stop/report, не выдумывать слои.

**G2** — изолированные обязательные smoke-тесты операций на CUDA/Metal по каждому заявленному поддерживаемому бэкенду; переносимые CPU unit-тесты DSP parity; не обещать протестированные платформы без реального железа.

**G3** — Python vs Rust тензоры и waveform-фикстуры (доверенный референс, только офлайн dev), закреплённые версии пакетов/seed/eval/дефолты, f32 attention baseline, сравнение. Целевые (неизмеренные) пороги на ограниченном детерминированном фикстуре: RMS error ≤ 1e-4 и maxabs ≤ 1e-3 при ref RMS > 1e-3, иначе relL2 ≤ 1e-3; тишина — только абсолютное. Это цели приёмки архитектора, не наблюдённые результаты; при провале — расследовать/report/переутверждать пороги, не тихо расширять. Референсный float32-путь без AMP по умолчанию. Можно сначала валидировать CPU-математику модели в тестах/dev явно, но production — запрошенный GPU без fallback.

Граничные случаи: чанки long/short, границы mono/stereo, сохранение rate, точное N выхода и float residual reconstruction с точностью f32 rounding, все конечные; неподдерживаемый вход/устройство — информативные ошибки. ASR: временные сегменты конечные, 0 ≤ start ≤ end ≤ duration, упорядоченные; без обещания точности слов; фикстура тишины и явный тест языка; реальная точность лирики — ручной тест с лицензированным песенным фикстуром. GPU интеграция — opt-in локальные ассеты; unit-тесты без сети. Cross-platform CI build checks — отдельно от runtime CUDA/Metal отчётов. Без бенчмарков/VRAM-утверждений до измерений.
