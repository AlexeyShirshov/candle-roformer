### Отмена зависшего субагента
Если субагент завис на tool call, повторное сообщение в его sessionID не является принудительной отменой. Использовать OpenCode HTTP API: POST /api/session/<sessionID>/interrupt (относительно API текущего экземпляра OpenCode). В этой сессии этот механизм вернул {"interrupted":true}, после чего пришёл статус cancelled. Определять адрес/доступ к текущему экземпляру по окружению, не фиксировать порт или секреты. Отменять только явно выбранную дочернюю сессию, не родительскую и не весь сервер; не применять kill-all. Если у основного агента нет прямого доступа, поручить точечную отмену coder. Сообщать об успешной отмене только по подтверждению API/статуса, а не после отправки инструкции STOP.
